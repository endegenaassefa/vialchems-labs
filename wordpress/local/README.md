# Local WordPress + WooCommerce Checkout

This stack runs a real WordPress + WooCommerce checkout site at `http://localhost:3002` for local preview.

```bash
bash scripts/bootstrap-local-wordpress.sh
```

It installs:

- WordPress on port `3002`.
- WooCommerce.
- Storefront parent theme.
- `vialchem-checkout-theme`.
- `vialchem-gateway-placeholders`.
- `vialchem-local-checkout-preview`, a local-only helper that renders the placeholder order-pay URL generated by the Next.js dev handoff.

The checkout nav links point back to `http://localhost:3001` through `VIALCHEM_MAIN_SITE_URL`, matching the production checkout-only behavior where `shop.vialchemlabs.net` navigation returns to `vialchemlabs.net`.

Local admin:

- URL: `http://localhost:3002/wp-admin/`
- Username: `admin`
- Password: `admin`
