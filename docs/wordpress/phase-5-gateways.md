# Phase 5 Gateway Configuration

Status: placeholder-backed. BTCPay, Link Money, Stripe, PayPal, Apple Pay, and Google Pay are represented in the configuration, but live processing is blocked until real credentials are supplied.

## Evidence

- Main site payment selector lives in `components/PaymentMethodSelector.tsx` and lists Link Money, Bitcoin, cards, Apple Pay, Google Pay, and PayPal as available at secure checkout.
- Main site order handoff lives in `app/api/create-woo-order/route.ts` and stores `_preferred_payment_method` in Woo order metadata.
- BTCPay Server documentation says the WooCommerce V2 plugin is the current bridge between BTCPay Server and WooCommerce and can be connected with the API key wizard.
- WooCommerce payment gateway API documentation covers custom payment methods using WooCommerce gateway classes.
- WooCommerce REST API payment gateways documentation says gateway records can be viewed and updated through the `payment_gateways` endpoint.
- WooCommerce webhook documentation identifies `X-WC-Webhook-Signature` as a base64 HMAC-SHA256 hash of the payload.

Official references:

- https://docs.btcpayserver.org/WooCommerce/
- https://developer.woocommerce.com/docs/woocommerce-payment-gateway-api/
- https://developer.woocommerce.com/docs/apis/rest-api/v3/payment-gateways/
- https://woocommerce.github.io/woocommerce-rest-api-docs/v3.html

## Install Placeholder Plugin

```bash
rsync -av wordpress/vialchem-gateway-placeholders/ PLACEHOLDER_SSH_USER@PLACEHOLDER_HOST:/path/to/wp-content/plugins/vialchem-gateway-placeholders/
wp plugin activate vialchem-gateway-placeholders
```

## BTCPay Server

Install and activate:

```bash
wp plugin install btcpay-for-woocommerce --activate
```

Recommended configuration path:

```text
WooCommerce > Settings > BTCPay Settings
BTCPay Server URL: PLACEHOLDER_BTCPAY_URL
Connection method: API key wizard
Store: PLACEHOLDER_BTCPAY_STORE_ID
API key: PLACEHOLDER_BTCPAY_API_KEY
Webhook: generated by wizard
```

Payment tab:

```text
WooCommerce > Settings > Payments
BTCPay: enabled
Title: Bitcoin
Description: Bitcoin payment via BTCPay Server.
```

## Link Money

Preferred live path:

```text
Install official Link Money WooCommerce plugin from the merchant dashboard when provided.
Set merchant key: PLACEHOLDER_LINK_MONEY_API_KEY
Enable only after the plugin can create a live or sandbox bank-payment session.
```

Placeholder path:

```text
WooCommerce > Settings > Payments > Link Money
Enabled: no until PLACEHOLDER_LINK_MONEY_API_KEY is replaced
Title: Link Money / Pay by Bank
Description: Pay by bank at secure checkout.
```

The placeholder gateway fails closed if the API key is empty or starts with `PLACEHOLDER_`.

## Disabled Placeholders

Install optional official plugins without enabling them:

```bash
wp plugin install woocommerce-gateway-stripe
wp plugin install woocommerce-paypal-payments
```

Admin state:

```text
Stripe: disabled placeholder
PayPal: disabled placeholder
Apple Pay: disabled through Stripe placeholder
Google Pay: disabled through Stripe placeholder
```

The placeholder plugin removes common card/wallet gateway IDs from available checkout gateways unless a future approved implementation replaces that behavior.

## Woo Order Status Webhook

Create in WooCommerce:

```text
WooCommerce > Settings > Advanced > Webhooks > Add webhook
Name: VialChem main-site order status
Status: Active
Topic: Order updated
Delivery URL: https://vialchemlabs.net/api/woocommerce/order-webhook
Secret: PLACEHOLDER_WOOCOMMERCE_WEBHOOK_SECRET
API Version: WP REST API Integration v3
```

Next.js env:

```bash
WOOCOMMERCE_WEBHOOK_SECRET=PLACEHOLDER_WOOCOMMERCE_WEBHOOK_SECRET
```

Verification:

```bash
npm test -- --run tests/unit/woocommerce/webhook.test.ts
curl -i -X POST https://vialchemlabs.net/api/woocommerce/order-webhook
```

Unsigned `curl` should return `401` after `WOOCOMMERCE_WEBHOOK_SECRET` is configured.
