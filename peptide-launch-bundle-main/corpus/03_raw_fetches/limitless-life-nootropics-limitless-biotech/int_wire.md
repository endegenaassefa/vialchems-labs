# International Wire Transfer Instructions

When sending a wire/transfer, make sure to add your order number as a reference. We currently accept **EUR** , **GBP** , **CAD** , and A**UD** directly, so no exchange rate will be applied. The corresponding wire/transfer instructions _**must be**_  used in order to avoid conversion fees.

 

**NOTE: If your currency is not listed, please use the SWIFT USD wire instructions provided.**

 

Intermediary Bank and Exchange Rate fees are paid by Client/Sender. Charge method code would be 'OUR'. 

 

Using the wire/transfer instructions for your currency and sending in that currency could significantly reduce fees, see below for more details:
