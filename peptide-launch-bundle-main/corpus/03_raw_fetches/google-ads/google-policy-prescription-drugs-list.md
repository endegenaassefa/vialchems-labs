# Prescription drugs reference list — peptide-relevant entries

URL: https://support.google.com/adspolicy/answer/2430794 (accessed 2026-05-06)

## Document description (verbatim)

"This list provides a reference for prescription drugs that Google Ads monitors as part of the Healthcare and medicines policy."

## Peptide compounds checked against the list

**Present in the list:**
- semaglutide
- tirzepatide

**NOT found in the list:**
- BPC-157
- TB-500
- IGF (any variant)
- GHK / GHK-Cu
- CJC (1295)
- Ipamorelin
- Growth hormone (generic)
- Sermorelin
- Melanotan / Melanotan II
- Thymosin (alpha-1 / beta-4)
- Generic "peptide"

## Interpretation

Only the GLP-1 RAs (semaglutide, tirzepatide) are explicitly enumerated as restricted drug terms; this is the bridge that triggers Google's prescription-drug certification requirement when a research-peptide vendor lists those compounds. The classic "research peptide" catalog (BPC-157, TB-500, melanotan, thymosins, etc.) is not specifically named — meaning enforcement happens via the catch-all clauses in the Unapproved Substances policy and via Google's broader Misrepresentation / Inappropriate Content guidelines, plus by ad reviewer judgment of landing-page intent.
