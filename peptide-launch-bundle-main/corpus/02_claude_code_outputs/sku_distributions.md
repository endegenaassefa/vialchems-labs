## Method notes

- Per-mg values rounded to 4 decimal places with banker's rounding.
- Percentiles computed via linear interpolation on the sorted distribution.
- IQR = 75th percentile minus 25th percentile.
- Outliers flagged when value < p25 - 1.5xIQR or > p75 + 1.5xIQR.
- 'Price clustering observed' fires when coefficient of variation < 0.10 across >=5 priced vendors.
- Rows with `peptide_canonical = uncertain` or empty are excluded from grouping per spec.
- Rows with `per_mg_price_usd = uncertain` or empty are excluded from distribution stats but still counted in vendor coverage.
- A peptide is included with full distribution if any priced rows exist regardless of vendor_status; vendor-status breakdown is reported per section.
