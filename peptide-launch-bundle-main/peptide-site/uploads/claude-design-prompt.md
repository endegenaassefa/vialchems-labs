# Claude Design Prompt

Use the uploaded pharmaceutical vial asset as the primary 3D product object.

Asset:
- `vial-v2.glb`
- Separate meshes: `GlassBodyMesh`, `PowderFillMesh`, `CyanRingMesh`, `SilverBandMesh`, `BlackCapMesh`
- The glass body is transparent, the powder is matte white, the cap is glossy black, the silver band is metallic, and the cyan ring is bright `#00F5FF`.

Please create a polished dark product/landing-page concept for a pharmaceutical vial. The first viewport should feature the 3D vial prominently, with a premium clinical/science aesthetic.

Requirements:
- Use a dark background similar to `#0A0A0A`.
- Keep the vial proportions and materials intact.
- Show the vial as an interactive 3D object if possible.
- If you build a web prototype, use Three.js or React Three Fiber and load `vial-v2.glb` directly.
- Do not use Draco compression.
- Make the design feel clean, modern, precise, and suitable for a biotech/pharmaceutical brand.
- Explore 2-3 visual directions if possible.

The reference preview image is included only to show the intended look if the GLB cannot be rendered directly.
